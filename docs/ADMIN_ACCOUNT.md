# Предустановленная учётная запись администратора

Первого админа нельзя назначить через интерфейс приложения (некому выдать
роль), поэтому он создаётся вручную один раз через дашборд Supabase.

## Учётные данные (сменить при первом входе!)

- Email: `admin@airsoft-economy.local`
- Временный пароль: `Airsoft-Adm1n-2026!`

Приложение принудительно попросит сменить этот пароль сразу после первого
входа — дальше войти со старым паролем будет нельзя.

## Как создать аккаунт

1. Supabase Dashboard → **Authentication → Users → Add user**.
2. Email: `admin@airsoft-economy.local`, Password: `Airsoft-Adm1n-2026!`.
3. Включите **Auto Confirm User** (иначе понадобится подтверждение по почте,
   а этот адрес не существует).
4. Сохраните — на аккаунт автоматически создастся запись в `profiles`
   (через триггер `handle_new_user` из `supabase/002_roles_and_games.sql`).

## Как выдать роль admin и включить принудительную смену пароля

Выполните в SQL Editor (после применения `supabase/003_admin_bootstrap.sql`):

```sql
update profiles
set role = 'admin', must_change_password = true
where id = (select id from auth.users where email = 'admin@airsoft-economy.local');
```

После этого войдите в приложении под этим email/паролем — оно сразу
покажет экран смены пароля.

## Важно

Этот файл попадает в git с открытым временным паролем — это нормально
только пока пароль не сменён и репозиторий приватный. После первого входа
и смены пароля можно удалить пароль из этого файла или пометить как
устаревший.
